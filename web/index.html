SSH CONNECTION

连接服务器文件系统

页面一直留在本机，通过 SSH 浏览、读取和修改服务器路径，delivery 直接保存在服务器，不跳转远端网页。

继承配置中的 User、Port、IdentityFile 和 ProxyJump，不复制密钥。

只需服务器有 SSH 和 Python 3.9+。无需安装本工作台、启动网页或开放 8767 端口；连接时自动通过 SSH 内存运行文件操作器。

macOS/Linux 支持密码弹窗：跳板机、目标服务器会分别提示认证，请核对提示中的账号/主机再输入。首次主机指纹需自行核验并确认；指纹变化仍会被 OpenSSH 拒绝。认证回答不写入日志或配置。原生 Windows 目前请使用密钥认证。
可直接选中，按 ⌘C / Ctrl+C 复制

支持在本页输入需求，让 Codex 在服务器项目执行、续聊和停止；trajectory 自动写入所选服务器目录的 agent_runs/，保存交付包含源码及真实运行轨迹。未找到 Codex 时可点击安装远端 Codex。模型 Key 经 SSH 只传入执行器内存，不写服务器配置。
